## Key Decisions

- **Storage-first write ordering** (bytes written before the Mongo row referencing them exists) → crash-safety: worst case is an orphaned blob, never a DB row pointing at bytes that don't exist.
- **Permission-widening badge shows groups only, never individual users** → naming a specific person's personal grant would leak more than the transparency goal requires; admins still see individuals in the existing admin screen.
- **Recycle bin/purge scoped to document-level only this phase** → folder-cascade delete and chunk/search-index verification (chunks don't exist until Phase 3/4) are separate, larger units — explicitly deferred, not silently dropped.
- **Region stays `europe-west`, Tel Aviv rejected** → Vertex AI's generative-AI data-residency guarantee covers only North America/Europe/Asia; splitting the topology would lose residency for the most sensitive data (chat/embedding calls) for no compliance benefit.
- **UI approach: one screen first via Stitch, driven by a written brief, before any broader visual system work** → owner wants to control theme/look-and-feel before it propagates to 25 more screens.

## Insights

- **CI had never actually passed since scaffold** — two silent config gaps meant the project's "single most important test asset" (the cross-tenant suite) had been invisible to the test runner the entire time, reporting a false "0 tests, pass" instead of failing loudly. Worth an occasional sanity check that CI is really exercising what it claims to.
- **A recurring test flake** (Argon2id-heavy `libs/auth` tests timing out under CPU contention when the *entire* workspace builds+lints+tests in parallel) showed up 3+ times this session, always in files nobody touched, always clean when run in isolation. Treat this class of failure as environment noise, not a regression signal, when it's isolated to `libs/auth` under a full-parallel run — but always verify in isolation before dismissing.
- **Spawned code-review subagents didn't reliably return findings** in this environment (tried twice — got a bare "Complete." with no content back, even after explicitly asking the agent to restate its report). Self-review directly (reading the diff, reasoning about it) became the reliable fallback this session — worth trying agent-based review again early in a fresh session to see if it's fixed, but don't burn much budget on it if it repeats.
